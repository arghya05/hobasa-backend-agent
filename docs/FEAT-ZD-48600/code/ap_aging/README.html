ap_aging

Accounts-payable aging service: groups open invoices into days-past-due buckets, and lists unpaid invoices more than 30 days past due with their vendor's risk level.

Public functions (ap_aging.__all__):

  • aging_buckets(invoices, as_of): total open amount per days-past-due bucket.
  • overdue_with_risk(invoices, as_of, risk_by_vendor): unpaid invoices more than 30 days past due, with vendor risk,

most overdue first.

  • overdue_rows_to_json(rows): the overdue rows as CT-1 JSON for ap_portal (amounts as two-decimal strings).

See docs/ap_aging.md for inputs, outputs, rules and examples.

Run CI: /usr/bin/python3 ci.py
